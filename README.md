# Passing Polygons

Landing page and tactical dashboard for the Passing Polygons project: how defensive shape affects chance creation, across 17 games from the A-League and the Bundesliga.

- `index.html`: landing page
- `dashboard.html`: interactive passing-lane dashboard (loads one match at a time from `data/`)
- `reports/final_report_parth.pdf`: full report

Data: SkillCorner open data and DFL / Bassek et al. 2025. Player photo by Ansey Photography on Pexels.
